# A-101 Project Assets Guide

Expected drawing files for A-101 (G+1 Residential Building):
1. ground-floor-plan.webp (or .png / .jpg) - Ground floor plan with room dimensions & annotations
2. first-floor-plan.webp (or .png / .jpg) - First floor plan with room dimensions & annotations
3. section.webp (or .png / .jpg) - Building sectional drawing showing heights & construction detail
4. elevation.webp (or .png / .jpg) - Exterior facade elevation
5. work-plan.webp (or .png / .jpg) - Floor-wise work planning schedule
6. A-101_2_Storey_Residential_Building_Documentation.pdf (also project-documentation.pdf) - Complete technical drawing set and documentation PDF [ADDED]

When files are placed here or uploaded via the UI "ADD DRAWING" / "ADD PDF" buttons, the portfolio automatically displays them.
